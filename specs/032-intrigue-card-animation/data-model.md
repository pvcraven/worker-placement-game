# Data Model: Intrigue Card Animation

**Date**: 2026-05-16

## Modified Entities

### IntrigueEffectResolvedResponse (shared/messages.py)

**Current fields**: `player_id`, `target_player_id`, `effect_type`, `resources_affected`

**New fields**:
- `intrigue_card_id: str = ""` — ID of the played intrigue card (for sprite loading)
- `intrigue_card_name: str = ""` — Display name (for game log)

**Reason**: Play animation requires all clients to know which card was played so they can display the face-up card sprite. Currently only the playing player knows which card they selected.

### No New Entities

All other entities remain unchanged:
- `QuestCompletedResponse` already includes `drawn_intrigue: list[dict]` with full card data
- `WorkerPlacedBackstageResponse` already includes `intrigue_card: dict` with full card data
- `AnimationEvent`, `EaseAnimation`, `AnimationManager` are used as-is

## New Assets

### intrigue_back.png

- **Location**: `client/assets/card_images/intrigue/intrigue_back.png`
